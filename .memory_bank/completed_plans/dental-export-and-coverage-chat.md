Директивы владельца 26.07: «по этим людям нет страховой программы/даты окончания — разбери каждого»;
«если это ГП — дата окончания = срок ГП, строку жирным»; «отчёт [Дентал Про] по умолчанию»;
«переделай [виджет "можно ли"] в виде чата (3-й раз): история в БД, видна всем с доступом,
контекст правил в LLM каждый раз»; «нерелевантное правило (коронковая часть) — исправь»;
лендинг v3.1 (центрирование, демо-баннер, без блока цифр, переименования) + англ. версия с USD.

## Сделано
1. **Причины пробелов июльской выгрузки (195 ФИО)**: 139 открепления без дат (РГС/РЕСО/Ренессанс),
   34 прикрепления без программы/даты (данные в преамбуле файла), 23 СОГАЗ «изменение данных»
   (не прикрепление вовсе), остальное — ГП/полные записи.
2. **Парсер** (`.mail-intake/extract_dataset.py`): преамбула списков («на срок: с … по …»,
   «по программе:», «Программа по факту:») → services/coverage_from/coverage_to всем строкам;
   РЕСО «Открепление с» → coverage_to (ключ 'открепл'); detach без даты → coverage_to=дата письма;
   списки «Вид изменяемых данных» (СОГАЗ) → doc_type='other' (мусор по канону).
3. **Backfill** (`.mail-intake/backfill_list_fields.py`, идемпотентный, только NULL):
   cto+600, программа+413, «прочее»×575 (99 файлов СОГАЗ). Вложение ищется и через архив
   (запись→zip, лист -z1.xls тем же письмом).
4. **Экспорт** (`app/api/registry/export/route.ts`): Дентал Про — ШАБЛОН ПО УМОЛЧАНИЮ
   (`?template=full` — полный); ГП-строки: дата=validUntil, ВСЯ строка жирным; программа-фолбэк
   из последнего прикрепления пациента (`latestProgramsByPatient`); типы other/service/… исключены.
5. **Чат по правилам** (замена AskCoverage): таблица `coverage_chat_message` (0025), общая история
   на пациента (авторы видны), server action `coverageChatSend`, контекст правил целиком + хвост
   истории (24) в LLM; без LLM — детерминированный ответ (answer-core) тем же вердиктом.
   `GuaranteeRequest` останется под чатом (услуга = последний вопрос).
6. **Релевантность**: GENERIC_WORDS в rulesForService («зуба» и т.п. не тянут чужие правила) +
   промпты: «не цитируй правила про другие услуги» (тест: коронковая часть не матчится).
7. **Лендинг v3.1** + `/land/en` (USD 150/250/400/500, авто-локаль Accept-Language, ?lang=ru escape).
8. **e2e-инфра**: локальный chromium падает после обновления ОС (int3, глибс/ядро) →
   прогон на прод-сервере `/root/sib-e2e` (см. ACCESS «e2e на сервере»); в конфиг добавлен
   `--no-sandbox --disable-dev-shm-usage`.
