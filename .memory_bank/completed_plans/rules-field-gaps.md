# Пробелы правил по полям (валидация золотым корпусом, аудит 2026-07-31)

Прогон `validate_rules.py` по всем PDF ГП/направлениям прода (golden.sql теперь сохранён:
`/opt/sib-intake/.mail-intake/golden.sql`). Правила НЕ ломаются (agree по покрытым полям 93–100%),
но систематически не покрывают часть полей — их закрывает LLM (дороже, менее предсказуемо).

## 1. Семантическое расхождение coverage (решить ПЕРВЫМ, ADR)
- **ВСК** covFrom/covTo agree 69/77%, **РГС** agree 15%: правило кладёт период ПОЛИСА,
  историческая LLM клала срок ПИСЬМА. По схеме `coverage_* = период обслуживания/действия полиса`
  → правило право (прецедент Альфы, D21). Но тогда срок ПИСЬМА должен попадать в `valid_until`,
  а у ВСК правило validUntil не находит (56 miss).
- Действие: зафиксировать ADR «coverage=полис, validUntil=срок письма — для всех СК»;
  поправить vsk_gp/rgs_gp (validUntil из «срок действия письма»); прогнать регресс;
  ИСТОРИЧЕСКИЕ записи ВСК/РГС с LLM-значениями скорректировать backfill-скриптом (только
  расхождения по этой семантике).
