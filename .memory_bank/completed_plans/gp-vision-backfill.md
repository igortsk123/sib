# План: добивка остатка Д2/Д3 через LLM (vision + текст)

Запрос владельца 2026-07-26: «писем без услуг 19, без срока 33 — поправить, возможно через ЛЛМ».
Детерминированные правила (ADR D28) своё отработали; остаток — сканы-картинки и письма без меток.
LLM на распознавание ПИСЕМ — давно боевой механизм (`method='llm'`), D23 (правила покрытия — только
агент) не затрагивается.

## Инвентаризация остатка (2026-07-26)

| Группа | Кол-во | Способ |
|---|---|---|
| Картинки png/jpg (Ингос 10, Зетта 5, Альфа 3, СОГАЗ 2, Совком 1) | ~21 | **vision-LLM** через тот же RU-прокси |
| PDF без текстового слоя (Ренессанс 3, Балт Ассистанс 1) | 4 | pdftotext → пусто → `pdftoppm` в png → vision |
| Без файла — текст в теле письма (РЕСО 23, ВСК 1, Лучи 1) | ~25 | **текстовый LLM**, тот же JSON-контракт |
| .doc Ренессанс | 1 | конвертация (libreoffice/catdoc) → текст → LLM; нет конвертера → vision по скрину нельзя → needs_review |
| rtf РЕСО с несработавшим правилом | 1 | посмотреть сырой текст; правка правила или LLM |

## Контракт и защита от ошибок LLM
- Один JSON-контракт полей (как `rules_gp`): services[], conditions, validUntil, coverageFrom/To,
  policyNumber, letterNumber, letterDate; строгая json-schema, temperature 0.
- **Валидация каждого ответа:** даты валидны и в диапазоне 2020–2030; `validUntil >= letterDate`;
  сверка ФИО из ответа LLM с ФИО письма в БД (фамилия совпадает — иначе ответ отброшен: защита
  «прочитал не то письмо»); полис сверяется с БД при наличии.
- **Запись только ПУСТЫХ полей** (ничего не перезаписываем); `field_status[поле]='ok_vision'|'ok_llm'`,
  `method += '+vision-backfill'`.
- LLM не нашёл срок/услуги (их нет в письме) → `needs_review=true`, `review_note='срок/объём в письме
  не указан (проверено vision/LLM)'` — честное состояние вместо молчаливой дыры.
- ПДн: изображения/текст уходят ТОЛЬКО через RU-прокси проекта (как весь LLM-трафик распознавания);
  в чат/логи — счётчики и маскированные образцы.

## Шаги
1. ✅ Инвентаризация (таблица выше).
2. Vision-скрипт на сервере (`backfill_vision.py`): картинки → base64 → chat с image_url → JSON →
   валидация → dry-отчёт → apply.
3. PDF без слоя: `pdftoppm -png -r 200` первая страница → тот же vision-путь.
4. Текстовый LLM для тел без файлов (+ .doc после конвертации, + rtf-разбор).
5. Пересчёт Д2/Д3; остаток = письма, где данных объективно нет (needs_review с причиной).
6. Синк скриптов, обновление памяти (ADR при отклонениях), коммит.

## Критерии готовности
- Д3 ≤ 5 и Д2 ≤ 10, ЛИБО каждый остаток помечен needs_review с причиной «в письме нет».
- 0 перезаписанных непустых полей; все LLM-ответы прошли валидацию ФИО/дат.
- Гейт зелёный, память обновлена.
