# Распознавание — Tier 1 сводка

## Форматы (§5)
Тело (plain+HTML) · PDF текст/скан(OCR) · DOC/DOCX · архивы с паролем (сопоставление письма-пары,
ручной fallback) · изображения→OCR. Детали — Tier 2.

## Поля
Пациент, страховая, согласование (статус/услуги/срок/лимит/условия), документ (тип/№/дата/источник/
ссылка). Перечень — `core/data-model.md` / `domain/product-spec.md` §7,13.

## Метод (§11)
Regex + правила по страховой + словари + **LLM** (OpenAI) + OCR/vision для сканов. Каждое поле — с
**уверенностью** (`confidence` jsonb) и ссылкой на фрагмент. Страховые → единый справочник.

## Контроль качества → ручная очередь
Ключевые поля найдены/не истёк/не дубль/есть оригинал; низкая уверенность → `needsReview`.
⚠️ Правила страховых — **гипотезы** (§18.2): проверять на письмах, расхождение → ADR.

⚙️ **Подход (ADR D10):** детерминированное ядро (раскрутка пересылки/base64, страховая по реестру доменов,
извлечение по форматам) + **LLM** (OpenAI прокси, рантайм `gpt-5.4-mini`, Structured Outputs) только
на поля; **gpt-5.5** — учитель-эталон. Наблюдаемость гибрида — `parse_log` (поле «уехало в LLM» = источник
сменил форму → правим правило).

⚙️ **D19 файл-first:** свободный путь двухпроходный — поля сначала из ВЛОЖЕНИЙ, тело — фолбэк; ФИО:
сила извлечения (метка) важнее источника; тип enroll/detach — по ИМЕНИ ФАЙЛА; `source` честный.
**D18 field_status:** absent=«нет данных» (искали файл+тело) / unreadable=«не распознано» (тех.сбой);
эмитит парсер, `prune_fs` снимает с дозаполненных. **D20 дубли:** `is_duplicate` на приёме (dupKey).
**D21:** `rules_gp.py` (**9 СК**) дозаполняет пробелы, LLM — подстраховка; валидация по золотому
корпусу. **D28:** mojibake-фикс rtf_text (cp1251 РЕСО; одиночные байты — в любом не-латинском
контексте, урок 19). **D31:** маркер ГП сильнее «открепл» из оговорки; детект «detach со сроком»=0.
**D33:** карта «тип документа→парсер/LLM» в `rules.parsing` + вкладка на карточке СК; онбординг —
`guides/onboarding.md`. **D36:** очередь «проверить» чистит **review-sweep**
(таймер 04:30; исключения СК в промпте; «не ДМС»→«прочее») — `guides/review-sweep-prompt.md`.
