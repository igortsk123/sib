# Lessons — плейбук уроков (что НЕ сработало и почему)

> **ACE: только инкрементальные правки bullets** (добавить/уточнить/`~~устарело~~`); целиком не
> переписывать, COMPRESS запрещён (CLEANUP_POLICY). **Читать перед каждым планом** (agent-workflow, Этап 1).
> Формат: `N. [дата] ситуация → подход → не сработало: причина → правило`.

## Уроки

**Уроки до 2026-07-24** (парсинг РТФ/BIFF, шапка таблицы как данные, приоритет силы
извлечения, коллизии фейков демо-стенда) перенесены в `../anti-patterns.md`.

6. [2026-07-25] «Всё сломалось» (Bash/сеть/Write) → причина: мои 60 МБ архивов забили квоту session-tmp → правило: тяжёлые времянки — на сервер; «exit 1 без вывода у всего» = сперва место/квота, потом сеть.

7. [2026-07-25] `.gitignore` со строкой `coverage/` съел папку `lib/server/coverage/` → файлы не попали в коммит, деплой падал на typecheck, сайт жил на старой сборке → правило: после создания папки с типовым именем (coverage/build/dist/tmp) проверять `git check-ignore -v`, в .gitignore якорить корнем.

8. [2026-07-25] Миграции, применённые вручную на прод, обрушили автодеплой (drizzle применял повторно, падал на «already exists»; старый контейнер жил, и это выглядело как «раздела нет») → правило: миграции всегда идемпотентные (IF NOT EXISTS / DO-блок с EXCEPTION).

9. [2026-07-25] Загрузил правила ООО «ОСЖ РЕСО-Гарантия» (страхование жизни) вместо САО «РЕСО-Гарантия» — 57 правил удалены → правило: перед экстракцией сверять юрлицо в титуле документа с отправителем писем.

10. [2026-07-25] Сопоставление услуги с ГП по общим словам дало ложное совпадение «имплантация зуба» ↔ «лечение 25 зуба» (слово «зуба») → правило: сравнивать тип вмешательства И номер зуба; поймал unit-тест, написанный до реализации.

11. [2026-07-25] Экстракция «для галочки» (1 правило на 35 страниц) выглядит как сделанная работа → правило: плотность правил на страницу проверяет `tools/audit-sources.py`, заглушки ловятся автоматически.

12. [2026-07-25] UI: `TableCell`/`TableHead` из shadcn несут `whitespace-nowrap` (перебивать `whitespace-normal`, иначе таблица едет); `DropdownMenuItem` Radix глотает submit вложенной формы (выход из аккаунта не работал) → вызывать server action напрямую + запасной путь `/logout`.

13. [2026-07-25] РТФ РЕСО: 192 ГП «без услуг» — не потому что данных нет, а mojibake (сырая cp1251 через latin-1: «ÓÇÈ ùèòîâèäíîé»; МЕТКИ полей целы, ЗНАЧЕНИЯ битые) → правило: «поле пустое при заполненном соседнем» = сперва смотреть сырой текст экстрактора, а не дописывать regex.

14. [2026-07-25] psql построчный парсинг ломается на многострочных полях (body_text, conditions: «expected 11, got 10») → правило: выгрузка с `-R $'\x1e'` (record separator) + split по нему; `\n` внутри полей сохраняются.

15. [2026-07-25] `Number.toLocaleString("ru-RU")` вставляет U+202F (узкий NBSP) — при копировании в письмо/почтовик ломается вид → в генерируемых текстах разряды разделять обычным пробелом (regex), не локалью.

16. [2026-07-25] e2e «все тесты на /login»: `drizzle-kit` и auth.setup НЕ читают `.env.local` — нужен экспорт `DATABASE_URL`/`TEST_LOGIN_CODE` в окружение прогона; `setup.skip(!TEST_CODE)` молча скипает вход, и flows валятся загадочно → правило: перед e2e `set -a; source <(grep -E '^(DATABASE_URL|TEST_LOGIN_)' .env.local); set +a`.
