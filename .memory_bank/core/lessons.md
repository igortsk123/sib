# Lessons — плейбук уроков (что НЕ сработало и почему)

> **ACE: только инкрементальные правки bullets** (добавить/уточнить/`~~устарело~~`); целиком не
> переписывать, COMPRESS запрещён (CLEANUP_POLICY). **Читать перед каждым планом** (agent-workflow, Этап 1).
> Формат: `N. [дата] ситуация → подход → не сработало: причина → правило`.
