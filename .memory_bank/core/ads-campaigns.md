  713064874 ГП ДМС общая · 713064875 ДМС-операционка · 713064876 Дополнение к МИС. DailyBudget 300₽/д каждая.
- **Чистка 28.07 (день 1: все 5 кликов — пациенты, отказы 50–67%, 0 lead):** +35 минусов на все
  кампании (телефон/заказать/купить/полис/что-такое/бренды клиник/бухучёт…), SUSPENDED пациентские
  фразы К2 (группы «Сроки», «Бренды СК», «заказать ГП дмс»). Лендинг не виноват (2/6 визитов кликнули
  демо). План: `completed_plans/ads-bounce-cleanup.md`. Пересмотр запросов через 2–3 дня.
- Лендинг **/land** v3.1: фокус «перестаньте терять деньги на невыплатах ДМС», 2 опции
  (реестр / ИИ-помощник), тарифы `[[pricing]]`, БЕЗ формы — прямые контакты + демо-баннер (/demo);
  /land/en с автолокалью (Accept-Language без ru → 307, цены USD). Детали макета — Tier 2.
  /land/privacy — полная политика конфиденциальности по образцу 2mnenie.online (27.07, 13 разделов).
- **РФ-блокировки (проверено с ру-сервера):** t.me и wa.me НЕ открываются; рабочее: `tg://resolve`,
  `api.whatsapp.com/send`, персональная ссылка MAX-профиля (max.ru/u/f9LH…, по номеру ссылок у MAX
  не бывает). Ники/номера всегда дублем текстом.
- **Автотаргетинг задавлен 0,3₽** во всех группах (урок «мед»: слил 5000₽/час). Регион — вся РФ.
- **Стиль наружных текстов (владелец 26.07):** БЕЗ длинных тире, человеческий тон («чтоб не
  выглядело как ИИ»); посыл hero дословно: «Оказали услугу пациенту, а страховая не заплатила.
  Знакомо?» + подзаголовок владельца; цифры без источника на лендинг не включать.
- Семантика/CPC/сезонность — [[demand-semantics]] (перепроверены лично 26.07).
- Метрика: счётчик 111048059 (API), 6 целей (lead — главная; +demo на клик демо-баннера),
  CounterIds на всех кампаниях. Контроль суммы: К4 не включаем → 900₽/д.
- Глубокий аудит 26.07 (3 агента) ПРИМЕНЁН: минусы/кавычки/ставки/тексты/sitelinks/моб.−30% —
  детали в Tier 2 («Аудит 26.07»).
- **Грабли API Директа:** vcards.add отключён, TextAd.Title2 молча игнорируется (warning 10165) —
  второй заголовок и визитка только через UI. DailyBudget минимум 300₽/д. Автотаргетинг suspend
  через keywords.suspend НЕЛЬЗЯ («невозможно выполнить действие») — только давить ставкой 0,3₽.
- Оплата за конверсии (цель «lead») — после ~10 конверсий.
