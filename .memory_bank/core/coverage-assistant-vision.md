# Ассистент покрытия ДМС — бизнес-идея (сверяться при каждом решении)

Сформулировано владельцем 2026-07-25. Расхождение решения с этим документом — повод переделать
решение, а не идею. Как устроено технически — [[coverage-pipeline]]; очередь работ — `plans/coverage-roadmap.md`.

## Зачем и для кого
**Врач у кресла и регистратура** должны за секунды понимать: **оплатит страховая это лечение или нет**
и **нужно ли сначала запросить гарантийное письмо**. Сегодня это знание лежит в 200-страничных PDF,
которые никто не читает, — из-за этого клиника теряет деньги на невыплатах.

## Требования владельца (жёсткие)
1. **Оперативность** — ответ мгновенный, без чтения документов и без ожидания LLM там, где можно
   ответить детерминированно.
2. **Минимум ошибок** — каждое утверждение с пунктом документа и датой редакции; неопределённость
   показывается явно («редакция обновилась, правило сверяется»), а не молча.
3. **Конвейер, а не разовая заливка** — новая редакция автоматически разносится на наши правила,
   в интерфейсе видна актуальная версия.
4. **Все правила доступны** — полный перечень с поиском и фильтрами, не только выжимка.
5. **В карточке пациента** — правила его программы по приоритету (программа сильнее правил страховой).

## Исполнитель экстракции (решение владельца)
Сейчас правила составляет **агент вручную, без внешних LLM**. После ~месяца тестовой эксплуатации
владелец планирует поставить на разнос **GPT-5 по API**. Поэтому исполнитель заменяем: контракт
`coverage_rule`, промпты (`guides/coverage-extraction-prompt.md`) и верификатор остаются, меняется
только тот, кто читает текст. ADR D23.

## Чего не хватает (ответственность владельца)
Программы из договоров клиники, в открытом доступе их нет:
**СОГАЗ «Амб. взрослые» и «Стоматология в ЛПУ»** (~3600 пациенто-строк) и **Альфа «Томск_*»**.
С ними покрытие вырастет с ~46% до ~90%.

## Метрики
Доля пациентов, для которых найдены правила их программы (онлайн на `/coverage/sources`);
время ответа в карточке; ноль правил без пункта-обоснования; ноль «молчаливых» неопределённостей.
