# Ассистент покрытия ДМС — бизнес-идея (сверяться с этим при каждом решении)

> Сформулировано владельцем 2026-07-25. Любое проектное решение по конвейеру покрытия
> проверяется против этого документа. Расхождение — повод переделать решение, а не идею.

## Зачем
Врач у кресла и **регистратура** должны за секунды понимать: **оплатит страховая это лечение или
нет**, и **нужно ли сначала запросить гарантийное письмо**. Сегодня это знание лежит в
200-страничных PDF, которые никто не читает — из-за этого клиника теряет деньги на невыплатах.

## Для кого (оба — равноправные пользователи)
- **Врач** — «можно ли удалить 7 зуб за 15 000 этому пациенту».
- **Регистратура** — то же самое до начала приёма: покрыто / не покрыто / нужен запрос ГП.

## Требования владельца (жёсткие)
1. **Оперативность.** Ответ мгновенный, без чтения документов и без ожидания LLM там, где можно
   ответить детерминированно.
2. **Минимум вероятности ошибки.** Каждое утверждение — с пунктом документа и датой редакции;
   неопределённость показывается явно («правила обновились, проверяются»), а не молча.
3. **Конвейер, а не разовая заливка.** Вышла новая редакция правил или условий → она
   **автоматически разносится** на наши правила; в интерфейсе видна **актуальная версия**.
4. **Все правила доступны** — не только выжимка: полный перечень с поиском и фильтрами.
5. **В карточке каждого пациента** — правила его программы, **упорядоченные по приоритету**
   (программа сильнее общих правил страховой).

## Как устроено (5 шагов конвейера)
| Шаг | Что | Состояние |
|---|---|---|
| 1 | Сбор документов страховых (правила + программы), локально, поллер раз в неделю | ✅ 13 документов |
| 2 | Документы → короткие правила «услуга → ДА/НЕТ/УСЛОВНО/СОГЛАСОВАНИЕ + пункт». Экстракция **вручную агентом, без внешних LLM** (решение владельца) | ✅ 488 правил, 5 СК |
| 3 | Письмо пациента → его программа (`program_alias`) → правила именно этой программы. **Программа сильнее общих правил СК** | 🔄 в работе |
| 4 | Карточка пациента: выжимка + полный список по приоритету, с пунктом и редакцией | 🔄 в работе |
| 5 | Вопрос врача/регистратуры → детерминированные гейты (программа, лимит, срок ГП, сумма) → остаток в mini-LLM → при необходимости черновик запроса ГП в страховую | ⏳ Ф2–Ф3 |

## Чего не хватает (ответственность владельца)
Документы по двум самым частым программам, их нет в открытом доступе — это приложения к договорам:
- **СОГАЗ «Амб. взрослые; Стоматология в ЛПУ»** — 1760 писем (четверть реестра);
- **Альфа «Томск_Максимум/Премиум/Оптимум»** — 104 письма.

## Метрики, по которым судим
- доля писем, для которых найдены правила именно их программы (было 33% на 2026-07-25 → цель ≥80%);
- время ответа в карточке (детерминированный путь — без обращения к LLM);
- ноль правил без пункта-обоснования; ноль «молчаливых» неопределённостей.
