### Снижение оплаты за пациентские клики (по силе эффекта)
1. **Оплата за конверсии** (стратегия Директа, цель Метрики «заявка/демо») — пациентские клики
   не тарифицируются. Нюанс: обучению нужно ~10 конверсий/мес → первые 2–4 недели вручную,
   потом переключить.
2. **Креатив-фильтр** (показы бесплатны, платим за клик): заголовок «Для клиник: …», лексика
   регистратуры (ДМС-отдел, страховые, Excel) — пациент не кликает.
3. **Минус-слова**: «как получить, нужно ли, как работает, мне, отзывы» (срезает ~230 пациентских);
   «сколько действует/срок» НЕ минусовать (там клиники); для «согласование со страховой» — авто-минусы.
4. **Корректировки**: будни 9–19 приоритет, вечер/выходные −50…−70%; десктоп приоритет,
   мобильные −30…−50%; РСЯ не включать — только поиск.
5. **Посадочная-квалификатор**: первый экран «Сервис для медицинских клиник» — пациент не доходит
   до конверсии и до ретаргета.
6. **Порядок бюджета**: старт с чистого ядра → общая фраза вторым эшелоном с обкатанным креативом.

Даже без фильтров эффективный целевой клик по общей фразе ≈ 150–300 ₽ (при 70% пациентских) —
запуску не мешает; фильтры возвращают к 50–100 ₽.

### Как переснять CPC
```bash
TOKEN=<YANDEX_DIRECT_TOKEN из _secrets/ACCESS.md>
curl -s -X POST https://api.direct.yandex.ru/live/v4/json/ \
  -d '{"method":"CreateNewForecast","token":"'$TOKEN'","param":{"Phrases":["..."],"GeoID":[225],"Currency":"RUB"}}'
# → id; подождать ~20с →
curl -s -X POST https://api.direct.yandex.ru/live/v4/json/ -d '{"method":"GetForecast","token":"'$TOKEN'","param":<id>}'
# поля: Min/Max (гарантия), PremiumMin/PremiumMax (спецразмещение); после — DeleteForecastReport
```

## Как переснять данные

```bash
KEY=<Api-Key из _secrets/ACCESS.md>
curl -s -X POST 'https://searchapi.api.cloud.yandex.net/v2/wordstat/topRequests' \
  -H "Authorization: Api-Key $KEY" -H 'Content-Type: application/json' \
  -d '{"phrase":"гарантийное письмо дмс","numPhrases":30,"regions":["225"]}'
```
